How these estimates work

Q4-class weights use roughly 0.60 bytes per parameter. We add 15% runtime overhead and 2 GiB for context and workspace. “Likely fits” keeps a 20% free-memory margin. Real requirements depend on model architecture, context and quantization. GPU memory and model quality are not assessed. Speed requires a real benchmark.
